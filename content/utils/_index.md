## Tools

This section collects ready-to-use tools, usage notes, and project documentation.

Current tools:

- [`npnp`](/utils/npnp/): a Rust CLI that generates Altium and KiCad libraries from LCSC/EDA data for scripts, batch jobs, and CI.
- [`SeEx`](/utils/seex/): a Rust desktop tool for organizing parts and exporting EDA libraries in batches.
- [`ARMUP`](/utils/armup/): a one-command installer for the `Cortex-M` embedded toolchain on `Windows`.
